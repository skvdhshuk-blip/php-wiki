# 事故响应

当前严重事故的第一响应负责人是事故指挥官。 [[source:raw/incidents.md|sha256:{{sha256:raw/incidents.md}}|lines:2-2]]

责任链为值班工程师发现、事故指挥官升级、安全负责人协助处置、服务负责人主持复盘。 [[source:raw/incidents.md|sha256:{{sha256:raw/incidents.md}}|lines:3-3]]

旧版手册把服务负责人写成第一响应负责人，和当前规则冲突。 [[source:raw/incidents.md|sha256:{{sha256:raw/incidents.md}}|lines:4-4]]

事故值班表在季度开始前完成，并避开发布冻结窗口。 [[source:raw/incidents.md|sha256:{{sha256:raw/incidents.md}}|lines:5-5]]
