# PHP Wiki brand visual evidence

当前图像（the current image）清晰使用红色几何线条（red geometric linework），顶部有两个突出的立方体轮廓（two prominent cube-like outlines），并由折线底座连接。 [[source:raw/php-wiki-mark.png|sha256:{{sha256:raw/php-wiki-mark.png}}|region:entire transparent canvas and red geometric mark]]

该标志（the mark）用于在应用界面和验收文档中标识 PHP Wiki。 [[source:raw/brand-guidelines.md|sha256:{{sha256:raw/brand-guidelines.md}}|lines:3-3]]

当前文字规范（the current written guide）也明确为红色线条和两个突出的立方体轮廓。 [[source:raw/brand-guidelines.md|sha256:{{sha256:raw/brand-guidelines.md}}|lines:2-2]]

旧版规范（the archived guide）写的是蓝色和一个立方体，与当前图像及当前规范冲突。 [[source:raw/brand-guidelines.md|sha256:{{sha256:raw/brand-guidelines.md}}|lines:4-4]]

视觉结论（visual claims）必须绑定精确图像区域。 [[source:raw/brand-guidelines.md|sha256:{{sha256:raw/brand-guidelines.md}}|lines:5-5]]
