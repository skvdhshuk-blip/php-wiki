# 工作方式与远程办公

当前远程办公申请至少提前 3 个自然日提交，并由员工经理审批。 [[source:raw/work-arrangements.md|sha256:{{sha256:raw/work-arrangements.md}}|lines:2-2]]

办公室办公不需要远程申请；服务负责人仍对交付负责。 [[source:raw/work-arrangements.md|sha256:{{sha256:raw/work-arrangements.md}}|lines:3-3]]

远程员工对安全与可用性负责，紧急例外由经理批准。 [[source:raw/work-arrangements.md|sha256:{{sha256:raw/work-arrangements.md}}|lines:4-4]]

旧规则要求提前 5 个自然日，与当前 3 日规则存在冲突。 [[source:raw/work-arrangements.md|sha256:{{sha256:raw/work-arrangements.md}}|lines:5-5]]
