# Release operations
Emergency releases require approval from the release manager; the quarterly deployment freeze begins on December 15.
A rollback is triggered when error rate exceeds 10 percent or the health check fails, and the service owner owns the rollback.
The archived release calendar begins the deployment freeze on December 10, conflicting with the current December 15 rule.
An older rollback note assigns rollback ownership to the incident commander, conflicting with the current service-owner rule.
Written deployment totals are Q1 12, Q2 18, Q3 24, and Q4 9.
